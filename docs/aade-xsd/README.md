# Επίσημα AADE myDATA XSD

Τα αρχεία στον φάκελο `v2.0.1` προέρχονται αυτούσια από το τρέχον επίσημο production πακέτο της ΑΑΔΕ:

`https://www.aade.gr/sites/default/files/2026-03/v2.0.1%20XSDs.zip`

Τα αρχεία στον φάκελο `v2.0.2-preofficial` προέρχονται αυτούσια από το νεότερο πακέτο που δημοσιεύει η ΑΑΔΕ στο δοκιμαστικό περιβάλλον:

`https://www.aade.gr/sites/default/files/2026-06/NEW_VERSION_2_0_2.zip`

Η v2.0.2 χαρακτηρίζεται `preofficial` από την ίδια την ΑΑΔΕ και οι αλλαγές της αφορούν κυρίως παραστατικά διακίνησης. Το `npm run test:xsd` ελέγχει τα XML ΑΠΥ, ΤΠΥ, ΤΑΚΚ και πιστωτικών τόσο απέναντι στην production v2.0.1 όσο και στη sandbox v2.0.2.
